### 2.7. Lecciones aprendidas

- Tests que leen `data/` real rompen en cuanto el bot cambia
  el universo (255 -> 287). Solucion: MAPPINGS_DIR + tmp_path,
  no relajar los asserts.
- `git add` selectivo sin `git status -sb` completo puede dejar
  ficheros fuera del commit (bug reincidente, ya en HANDOFF
  sesion 14 §6.2).
- `verifica_gobernanza.py` solo validaba 'el YAML parsea'.
  Duplicados de clave, ids embebidos y tipos incorrectos se
  colaban. 2 checks nuevos cierran esa puerta.
- Scripts PowerShell con `'<placeholder>'` interpolado rompen
  si el SHA es numerico. Usar `chr(39)` o comillas simples
  escapadas.
- Here-string multilinea en consola interactiva: no fiable.
  Preferir arrays de lineas. Repetido de sesion 14.

**P7 Fase 4 observacion vs formato (2 commits, a4a28d9e + a6a8f017).**

de formato/render). 7 funciones migradas: flows_secondary,
mte_confirmation, validation_gate, download_market_data,
download_stock_prices, sector_breadth, data_quality.

**Bug de propagacion (a6a8f017).** 3 de las 7 funciones tenian
el raise DENTRO de su propio `try/except Exception`. Se capturaba,
se imprimia "omitido" y se devolvia None. Silencio, el bug
original. Movido el raise antes del try en _compute_mte,
compute_flows_secondary y _compute_sector_breadth_health (con
early-return de df_stocks vacio antes del raise). Detectado por
test de contrato `test_compute_sector_breadth_health_raise_si_
none`. Sin el, el raise era fe.

**Except silenciosos (b8b0de96).** 164 ficheros, 51 `except
Exception`. 0 bare_except. 4 bugs reales: write_artifact_with_
manifest (fail-close con fail_on_invalid, callers de pipeline
pasan True), str(e) en except anidado (str(be)),
run.py:252/352 pass→print. 46 except restantes clasificados
(fail-soft intencional, log, fallback de helpers).

**Cache freshness (4150a68e).** 3 bugs: data_loader no validaba
tickers en cache-hit (ETF nuevo sin descargar hasta 23h);
CSV legacy (market_data.csv, stock_prices.csv) resucitaba por
mtime (eliminado, solo parquet); min_coverage=0.90 hardcoded
(CACHE_MIN_COVERAGE en config.settings).

**Rate limiting (780930e6).** 2 bugs: retry_utils.retry_call con
`backoff * attempt` daba sleep(0) en el primer retry (primer
reintento inmediato, agrava 429); stock_data_loader retry
individual sin sleep entre tickers fallidos (N requests
back-to-back, 429 garantizado). Fix: `backoff * (attempt + 1)`
y `try/finally` con `time.sleep(delay)` en el bucle de retry.

**Docs firma auditor (68e9701b).** 4 docs con seccion de firma
nueva (59 §8, 70-v2b §6, 70-v2d §7, 73 §7). Formato unificado:
Aprobado / Aprobado con cambios / Rechazado. 7 mensajes de

**Deudas menores no auditadas**: resource leaks (open sin with,

## 6. NOTAS CRITICAS

### 6.1. Operativas (PowerShell / Windows)

- **Runs locales SIEMPRE en consola visible.** Nunca
  `Start-Process -WindowStyle Hidden`. El usuario lo exige desde
  sesion 14.
- Worktree antes de procesos largos.
- `python` sin ruta resuelve al alias Microsoft Store. Usar la ruta
  real: `C:\Users\marta\AppData\Local\Python\pythoncore-3.14-64\python.exe`.
  O `py` (launcher).
- stdout bufferizado en `Start-Process -RedirectStandardOutput`: el log
  no crece hasta el final. Usar checkpoint, no log, para monitorizar.
- `Set-Content -Encoding UTF8` en PS 5.1 anade BOM. Usar
  `[System.IO.File]::WriteAllText(..., [System.Text.UTF8Encoding]::new($false))`.
- `AppendAllLines` no acepta encoding. Leer + concatenar + WriteAllLines.
- CRLF en el repo: `Replace` con `\n` falla. Usar arrays de lineas o
  `ReadAllLines` + `WriteAllLines`.
- `$var:` en here-string se interpreta como referencia a unidad. Usar
  `${var}`.
- Here-string multilinea en consola interactiva: no fiable. Preferir
  arrays de lineas.

### 6.2. Git

- **`git add` selectivo omitio scripts en varios commits.** Local pasaba
  (working tree con el fix), CI fallaba (usaba la version antigua).
  Antes de cada commit de gobernanza: `git status -sb` y revisar que
  TODOS los ficheros modificados relevantes estan staged.
- Workflow de commits: 1 cambio = 1 verificacion = 1 commit. No mezclar.
- Si el bot pushea a main durante la sesion: `git fetch` + `git rebase
  origin/main` (commits locales no pusheados, seguro). Nunca `git merge`.
- Commit SHA para REGISTRO: `git rev-parse --short HEAD` DESPUES del
  commit. Para FIXED que necesita SHA, primero commit docs sin REGISTRO,
  luego SHA, luego commit REGISTRO.
