## 5. NOTAS CRITICAS

### 5.1. Operativas (PowerShell / Windows / BOM)

- Here-strings @""..""@ y @'..'@ rotos al pegar en esta maquina.
  Patron: array de lineas + Set-Content -Encoding UTF8 a fichero .py
  + py fichero.py. Nunca py -c con strings > ~2KB.
- **No anidar here-strings de PowerShell con scripts Python**:
  un bloque @'..'@ que contiene codigo Python con triple-comilla
  adentro rompe el parser.
- **Ruta absoluta SIEMPRE con [IO.File]::* en PowerShell**: el CWD
  de .NET puede ser C:\WINDOWS\system32 (no D:\Macro_Sectorial). Usar
  `$absPath = (Resolve-Path ...).Path` antes de cualquier
  [IO.File]::WriteAllText/AppendAllText/ReadAllBytes.
- **Here-strings de PowerShell >10KB se truncan silenciosamente**.
  Escribir en chunks de <= 2KB con WriteAllText (primer chunk) +
  AppendAllText (resto). Verificar tamano tras cada chunk.
- **PS parsea `"$var: ..."` como drive-variable**. Usar `-f` para
  formatear: `Write-Host ("linea {0}: {1}" -f $i, $ln)`.
- **YAML: indentacion top-level = 0 en `universe_expansions.yaml`,
  no 2**. Los bloques nuevos deben copiar el nivel exacto del
  original (cabecera a col 0, campos a 2, guiones a 2).
- **BOM UTF-8** presente en varios ficheros. Leer con utf-8-sig,
  escribir preservando BOM.
- **EOL:** `05_BITACORA.md` working tree CRLF (indice LF por `attr/text eol=lf`); `01_METODO.md`, `00_ARRANQUE.md` y HANDOFF canonico en LF. `docs/handoffs/HANDOFF.md` es CRLF (archivo historico, obsoleto). Detectar con `git ls-files --eol` (no `| Out-String`).
- python sin ruta resuelve a Microsoft Store. Usar py o ruta real.
- **monkeypatch.chdir no reubica paths de __file__**: si el SUT
  exporta RESULT_PATH/OUT_PATH/*_DIR a nivel de modulo, chdir(tmp_path)
  no basta. Monkeypatchear el simbolo. Ver 01_METODO seccion 3 (bug
  GUARD-COVERAGE-TEST-CONTAMINA-STATE, 2026-11-02).

### 5.2. Git

- git push SIEMPRE con if ($LASTEXITCODE -ne 0) que haga fetch +
  pull --rebase + push. Sin esto, falsos positivos si el bot pushea.
- Tras push rechazado: git fetch + git pull --rebase origin main
  y re-verificar gobernanza ANTES del segundo push (leccion
  4dd66ce8).
- git add selectivo + git status -sb completo antes de commit.
- 1 cambio = 1 verificacion = 1 commit.
- Para FIXED con SHA: commit codigo sin REGISTRO, luego SHA,

### 5.5. PowerShell / Python (lecciones 2026-11-04)

- **if inline en PowerShell no es expresion, es sentencia.**
  No usar como valor asignable. Usar ternario o bloque previo.
- **exit en PowerShell cierra la sesion completa**, no solo el
  script. Usar return para abortar un bloque, o throw para error.
- **var -ne string-vacia es True para array vacio.** Usar
  if (var) que es falsy para array vacio, null y string vacia.
- **Escaping de comilla simple en PS no es bash-style.** En
  single-quoted PS, la comilla se duplica. Alternativa robusta:
  construir el caracter con chr(39) en Python.
- **Tests que importan datetime.date sin usarlo**: pyflakes
  warning real. Quitar el import, no silenciar.
- **generate_estado_sistema.py: pytest serial colgaba.** Fix:
  -n auto --dist loadfile + timeout=600. 137s vs mas de 10 min.
