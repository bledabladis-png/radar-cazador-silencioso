## 5. NOTAS CRITICAS

### 5.1. Operativas (PowerShell / Windows / BOM)

- **Here-strings `@"..."@` y `@'@` rotos** al pegar en esta maquina.
  Patron que funciona: array de lineas (`@(...)` con una linea por
  elemento) + `Set-Content -Encoding UTF8` a fichero `.py` +
  `py fichero.py`. Nunca `py -c "..."` con strings de mas de ~2KB
  (comillas anidadas, escapes `\`).
- **BOM UTF-8** presente en varios ficheros (`indicators/options_
  metrics.py`, `indicators/breadth_core.py`, `src/report/iae.py`,
  `tests/test_macro_regime_empty_input.py`). Leer con `utf-8-sig`,
  escribir preservando BOM: `(b"\\xef\\xbb\\xbf" if bom else b"")
  + t.encode("utf-8")`.
- **CRLF en test files**. `\r\n` en lugar de `\n`. Anclar anchors con
  `chr(13)+chr(10)` o hacer slicing por `find`/`replace` de substring
  unico (evita el problema).
- Runs locales SIEMPRE en consola visible.
- `python` sin ruta resuelve a Microsoft Store. Usar `py` o ruta real.

### 5.2. Git

- `git push` SIEMPRE con `if ($LASTEXITCODE -ne 0)` que haga fetch +
  pull --rebase + push. Sin eso, falsos positivos si el bot pushea
  concurrentemente.
- Tras push rechazado: `git fetch + git pull --rebase origin main`
  y push.
- `git add` selectivo + `git status -sb` completo antes de commit.
- 1 cambio = 1 verificacion = 1 commit.
- Para FIXED con SHA: commit sin REGISTRO, luego SHA, luego commit
  REGISTRO.

### 5.3. Workflow_dispatch

- **REGLA**: force=true NO entre 13:30-20:00 UTC (US market open).
  Verificar con `(Get-Date).ToUniversalTime()` antes. Lanzar a 19:19
  UTC el 29-10 fue error, cancelado antes de Commit.
- Slots seguros: pre-13:30 UTC o post-23:00 UTC.
- Scheduled slots: 17 23, 17 3, 17 5, 17 7, 17 11 (todos UTC).
